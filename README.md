# مواجهة الصور — حرب الجزر

لعبة عربية متعددة الأجهزة: لاعبان، عشر مناطق، خمس فئات مختلفة لكل لاعب، هجوم بصورة من فئة منطقة المهاجم، انتقال المنطقة المحتلة إلى فئة الهجوم، وشاشة حكم منفصلة للتلفاز.

## تشغيل محلي

```bash
npm install
npm start
```

ثم افتح http://localhost:3000.

## نشر Render

- Service type: Web Service
- Runtime: Node
- Build Command: `npm install`
- Start Command: `npm start`
- Branch: `main`

ارفع **محتويات** المجلد إلى جذر المستودع (وليس المجلد نفسه). يُفضّل رفع الملفات الخمسة دفعة واحدة. إذا كان package.json موجودًا مسبقًا، استبدله بالنسخة المرفقة.

## ملاحظات

- صور الأسئلة تُسترجع من Wikimedia Commons، بحد أقصى 60 نتيجة للفئة عند توفرها. قد تكون بعض الصور غير دقيقة أو غير متاحة، لذلك يختار الحكم الإجابة الصحيحة. لا تتوفر قاعدة صور منتقاة يدويًا بعد.
- التحديث بين الأجهزة يتم باستطلاع الخادم كل 1.8 ثانية، وليس WebSocket.
- الغرف والنتائج محفوظة في ذاكرة الخدمة فقط وتضيع عند إعادة تشغيلها أو سكونها. للاستخدام الدائم تحتاج قاعدة بيانات.
- لا توجد مصادقة للحكم؛ كل من يملك رابط الغرفة يستطيع التحكم بالنتائج. مناسبة للعب الودي فقط.
- هذه نسخة قابلة للعب وتجريب المزامنة، وليست النسخة النهائية ذات بنك صور موثّق وغير متكرر عبر كل الألعاب.
